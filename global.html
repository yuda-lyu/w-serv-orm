checkContract(contract) → {Boolean}

Description:

  • 驗證寫入契約(不合者拋Error，不靜默)

    規則: 須為純物件且只含 table、pk、fields、serverOnly、orderKey、scope 六鍵；pk 為非空字串；fields 為非空且不重複之非空字串陣列； serverOnly 若給予須為不重複之非空字串陣列且與 fields 無交集；orderKey 若給予須為非空字串，不得在 fields 內，亦不得等於 pk；scope 若給予須為函數；table 若給予須為非空字串。 契約以讀取當下之值驗證，不快取；建議使用端於啟動時對每份契約呼叫一次。

compareBaseline(rowsNow, baseline, contract) → {Object}

Description:

  • 以基準比對目前之列(伺服端於表鎖內以新鮮讀取之列呼叫)

    回傳 { ok: true }(相符：增、刪、改、名次皆無差異)，或 { ok: false, reason, added, removed, changed, reordered }： reason 為固定英文拒收鍵，baselineFormat(基準格式或版本不識；此時 added、removed、changed 為空陣列、reordered 為 false，未比對)、 rowNotFound(基準只含一列且該列已不在目前之列、且無新增列：逐列存檔時該列已被刪)、baselineMismatch(其餘不符)； added 為基準沒有而目前有之id，removed 為基準有而目前已無之id，changed 為兩邊皆有而摘要不同之id，皆依各自陣列之序； reordered 為布林，兩邊共有之列其相對次序不同者為true(他人重排；系統重編號而名次不變者不算)。 rowsNow 內之主鍵缺漏或重複拋 key 為 'rowsInvalid' 之Error(庫內資料異常，非客戶端之基準格式錯誤，不歸為baselineFormat)，值不可摘要者拋Error；契約不合者拋Error。

digestRow(row, contract) → {String}

Description:

  • 計算單列摘要(版本h1)

    規則(規格 §5): 取 contract.fields 依宣告之序(orderKey與serverOnly不入)；每值正規化後以JSON陣列序列化，取cyrb53，回傳 'h1:' + 14位16進位(補零)。 欄位頂層之 undefined、null、'' 為同一空值(含缺欄)；Date 轉ISO字串；BigInt 轉十進位字串；物件鍵遞迴排序(UTF-16碼元序)，陣列保序；數字與字串不互轉(1 與 '1' 不同)； 巢狀值只依JSON語意(物件鍵之值為undefined者略去，陣列之undefined元素為null，巢狀之null與''不等價)； 其餘非JSON值(function、symbol、NaN、±Infinity、無效Date、Map、Set、RegExp、類別實例等)與超過深度100或單列節點10萬者拋Error，不靜默略過；列本身須為一般物件(陣列、Map、Set、Date等拋Error)。

isBaselineValid(baseline) → {Boolean}

Description:

  • 判斷基準格式是否合法(含版本)

    合法: 陣列，每項為長度2之陣列 [非空字串id, 摘要字串]，摘要須為本模組已知版本之格式('h1:'加14位小寫16進位)，id不得重複；空陣列合法(空表)。 不識之格式或版本一律不合法，使用端不得降級為不帶基準。

pickWriteRow(row, contract) → {Object}

Description:

  • 取得寫入列(存檔採用客戶端值之欄位白名單): 只含 contract.pk 與 contract.fields 內且列上自有、值非undefined之欄位
